Deployment Guide

Step 1: Push to GitHub

# Create a new repository on GitHub, then:
cd 外贸网站
git remote add origin https://github.com/YOUR_USERNAME/suode-endoscopy.git
git push -u origin master

Step 2: Deploy to Vercel

  1. Go to vercel.com and sign up/login
  2. Click "Add New..." → "Project"
  3. Import your GitHub repository
  4. Vercel will auto-detect it's a static site
  5. Click "Deploy"

Step 3: Custom Domain

  1. After deployment, go to Project Settings → Domains
  2. Add your domain: suode-endoscopy.com
  3. Add the DNS records shown by Vercel to your domain registrar (Tencent Cloud)
  4. Wait for SSL certificate to be issued
